<objective>
Add per-instance try-catch to the tick loops in CosmeticManager and PetManager so a single failing instance never aborts the entire loop. Also add world-null guards to CosmeticInstance.tick(), PetInstance.tick(), and HologramVisibilityTracker.update() to prevent NPE when entities are in a partially-unloaded world. Finally, read and assess EmitterManager.tickAll() and TimelineManager.tickAll() for CORR-03 coverage — add try-catch if their tick() calls can throw, or document why protection is not needed.

Purpose: Eliminates silent tick-loop aborts and NPEs that cause cascading cleanup failures under normal server conditions (entity death mid-tick, world unload).
Output: CosmeticManager and PetManager with Logger-injected constructors and guarded tickAll(); CosmeticInstance, PetInstance, and HologramVisibilityTracker with world-null guards; EmitterManager and TimelineManager with CORR-03 assessment and comments.
</objective>

**EmitterInstance.tick() assessment (findings from planning):**
- Already has `World world = Bukkit.getWorld(worldName); if (world == null) return;` at line 39
- Does not touch Bukkit entity references that can become null mid-tick
- Calls `ScriptEngine.computeOffsets()` and `world.spawnParticle()` — these are server-side particle calls that Bukkit catches internally; invalid particle data would throw IAE but is caught by the outer try-catch in EmitterConfig.loadAll(), not here
- `ScriptEngine.computeOffsets()` could theoretically throw on malformed script, but that would be caught once at startup, not during ongoing ticks

**Decision for EmitterManager:** EmitterInstance.tick() is void-returning, has a world-null guard, and operates on block-coord data that cannot become null. It does not hold live entity references. The `world.spawnParticle()` call could throw `IllegalArgumentException` for invalid particle data — add a try-catch around `instance.tick()` in EmitterManager.tickAll() to be safe. Log at WARNING with the emitter ID.

Add this to EmitterManager.tickAll():
```java
public void tickAll() {
    // CORR-03 VERIFIED: EmitterInstance.tick() has a world-null guard. Per-instance try-catch
    // added to guard against unexpected particle API exceptions without aborting all emitters.
    for (EmitterInstance instance : emittersById.values()) {
        if (instance.isChunkLoaded()) {
            try {
                instance.tick();
            } catch (Exception e) {
                // Log at WARNING — a single bad emitter must not stop all other emitters
                java.util.logging.Logger.getLogger("ServerCore")
                        .warning("[ServerCore] EmitterInstance tick failed for id '"
                                + instance.getId() + "': " + e.getMessage());
            }
        }
    }
}
```

Note: EmitterManager has no logger field and no constructor to inject one. Use `Logger.getLogger("ServerCore")` — consistent with how Paper plugins name their logger. Do NOT refactor the constructor; that is out of scope for this plan.

**TimelineInstance.tick() assessment (findings from planning):**
- Already handles `origin.getWorld() == null` gracefully (returns empty audience)
- Calls `action.execute(origin, audience)` — TimelineAction implementations (PlaySoundAction, RunCommandAction, etc.) could throw if given bad origin or missing world
- The removeIf pattern in TimelineManager.tickAll() means an exception thrown by instance.tick() would propagate out of removeIf and abort the entire loop

**Decision for TimelineManager:** Add per-instance try-catch in tickAll() to prevent a failing action from aborting all running timelines. Log at WARNING with the timeline ID.

Add this to TimelineManager.tickAll():
```java
public void tickAll() {
    // CORR-03: Per-instance try-catch added. TimelineAction.execute() calls may throw
    // if origin world is missing or action config is invalid. One failing timeline
    // must not abort all other active instances.
    activeInstances.removeIf(instance -> {
        try {
            return !instance.tick();
        } catch (Exception e) {
            java.util.logging.Logger.getLogger("ServerCore")
                    .warning("[ServerCore] TimelineInstance tick failed for timeline '"
                            + instance.getTimeline().getId() + "': " + e.getMessage());
            return true; // Remove the failed instance
        }
    });
}
```

Only add the try-catch and comments — do not change any other method or field in either manager.
