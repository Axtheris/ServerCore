### Integration Defect

**Quest/NPC shutdown ordering:** `questStore.saveSync()` at line 520 precedes `npcTickTask.cancel()` at line 523. The correct order per LIFE-01 invariant is: cancel NPC tick task → save quest store → destroy NPC instances. Risk is low-medium (no quest tick task exists, so the race window is bounded by NPC dialogue interactions on the main thread during save).
