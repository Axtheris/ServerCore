<objective>
Pre-parse quest explore objective target coordinates at config load time into an immutable ExploreTarget record, eliminating per-tick String.split() and Double.parseDouble() allocations in QuestManager.handleExplore().

Purpose: On every server tick, for every online player with an active explore quest, `handleExplore()` calls `obj.getTarget().split(",")` (allocating a new String[4]) plus three `Double.parseDouble()` calls. The target string never changes after config load. Pre-parsing into an immutable record eliminates 100% of this per-tick allocation.

Output: ExploreTarget record nested in QuestObjective, pre-parsed in fromConfig(), used in handleExplore().
</objective>

```java
private static ExploreTarget parseExploreTarget(String locationStr) {
    if (locationStr == null) return null;
    String[] parts = locationStr.split(",");
    if (parts.length != 4) return null;
    try {
        return new ExploreTarget(
            parts[0].trim(),
            Double.parseDouble(parts[1].trim()),
            Double.parseDouble(parts[2].trim()),
            Double.parseDouble(parts[3].trim())
        );
    } catch (NumberFormatException | IllegalArgumentException e) {
        return null;  // caller logs warning (D-20)
    }
}
```
